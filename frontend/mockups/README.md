# Mockup visual del dashboard

Esta carpeta contiene una referencia visual estática para el dashboard de MoneyBuddy. Su objetivo es guiar la futura implementación del frontend en React, no reemplazar la aplicación productiva.

## Cómo abrirlo

Abrí `dashboard.html` directamente en un navegador desde esta carpeta:

```text
frontend/mockups/dashboard.html
```

La página usa assets locales desde `frontend/mockups/assets/` y la hoja de estilos `dashboard.css`.

## Alcance

Usá este mockup como referencia para:

- layout del dashboard y estructura de tarjetas;
- jerarquía visual, espaciado, colores y tipografía;
- dirección de marca de MoneyBuddy;
- ideas de presentación para gráficos y métricas.

No trates este mockup como código productivo final. La implementación en React todavía debe resolver:

- integración con la API de análisis financiero;
- validación de formularios y estados reales de interacción;
- etiquetas accesibles, estados de foco y estados deshabilitados;
- resúmenes semánticos para gráficos y métricas;
- comportamiento responsive en mobile, tablet, desktop y zoom del navegador;
- ajustes de contraste requeridos para cumplir WCAG AA.

## Nota para revisión

Cuando revises cambios en esta carpeta, evaluá primero la fidelidad visual y la dirección de producto. La preparación para producción corresponde a la implementación posterior en React.
